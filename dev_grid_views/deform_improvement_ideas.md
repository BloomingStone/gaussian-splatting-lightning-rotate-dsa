# 形变场改进方向分析（提高帧间信息融合度）

## 1. 问题本质：病态性来源

观测结构：
- 每帧只有 **1 个视角**（单目，C-arm 连续旋转）。
- 相位周期 60 帧，训练 140 帧 ≈ 2.3 个周期 → **每个相位平均只有 ~2.3 个视角**，单相位重建严重欠定。
- 同相位帧（如 frame 40/100/160 都是 phase 0.667）alpha 跨度大（-66°/+14°/+94°），角度稀疏。

主要病态来源：
1. **单相位稀疏角重建**：每个相位 ~2 帧，单靠同相位帧无法重建 3D，必须靠形变场**跨相位融合**信息。
2. **心跳非刚体运动**：形变场需表达连续、周期、低频、非刚体的位移，表达不足 → 重影/模糊。

造影剂流动为**次要因素**：其变化主要集中在前 40 帧，后 140 帧（训练集 frame 40~179）近似充盈，主干尤其稳定。故"同相位不同时间的 3D 差异"不是主要矛盾。

## 2. 心跳运动特征 → 可加先验

| 特征 | 对应先验/正则 | 实现思路 |
|------|--------------|---------|
| 周期性 | 形变场周期边界 d(phase=0)=d(phase=1) | 采样 phase 与 phase-1 位移，L2 差；或周期性编码 |
| 连续（时间） | 位移沿 phase 平滑 | 相邻 phase 位移 L2 / TV |
| 低频（时间） | 位移幅值小、变化慢 | 位移 L2 幅值正则 + 平滑 |
| 低频（空间） | 空间平滑 / 局部刚体 | 空间 TV、局部刚体约束、BSpline 低分辨率场 |
| 非刚体 | 保留局部位移自由度 | 不强制全局刚体 |
| 收缩主导 | 位移方向朝心脏中心 | 软约束 / 初始化位移方向 |
| 带动冠脉 | 冠脉点位移与邻近点相干 | 空间相干正则 |

## 3. 具体改进方案（按优先级）

### P1：周期性约束（最关键，两模型都缺）
- phase 0 与 phase 1 是同一心脏状态（舒张末期）。
- 强制 d(x, 0) = d(x, 1)，消除相位端点不连续（模糊来源之一）。
- 实现：随机采样 phase p 与 p−1，对同一点加 L2 位移差正则。

### P2：phase 方向平滑正则（r2g MLP 缺失）
- stage1 有 field_smooth_loss；r2g 纯 MLP 无任何形变正则。
- 加相邻 phase 位移差 L2，抑制形变场沿相位的抖动。

### P3：分离 time 与 phase（可选，降级）
- 心跳 = phase 函数（周期）；造影剂 = time 函数（单调，但后 140 帧近似充盈，次要）。
- 由于造影剂流动非主要矛盾，time 分离的收益有限；仅在 P1/P2/P4/P5 后仍不够时再考虑。

### P4：BSpline 低分辨率形变场（空间低频）
- r2g 已有 BSplineDeformModel（8×8×8 grid），天然空间低频，可抑制高频形变（针状/错位来源）。
- 与 MLP 对比。

### P5：点云 / 轨迹约束（均不使用 GT）
- **时序轨迹平滑**：同一点相邻相位位移连续。
- **局部距离保持（等距）**：心肌表面点间距近似不变，软约束。
- **单相位覆盖**：确保每个相位下高斯覆盖血管，避免欠采样。
- ⚠️ 注意：`central_line.npz`、`coronary_label.nii.gz` 均为 GT，**不可用于重建**（初始化/约束/正则）。

### P6：训练策略
- AST（相位噪声增强）r2g 可加（stage1 已有）。
- 同相位相邻 alpha 帧的光度一致性软约束。

## 4. 推荐实验顺序
1. r2g 加 P1+P2（周期性 + phase 平滑，最小改动，直接针对模糊/重影）。
2. r2g 换 BSpline 形变场（P4，验证空间低频先验）。
3. 点云中心线 / 轨迹约束（P5）。
4. r2g 加 time 分离 flow（P3，造影剂流动次要，可选）。

## 5. 随机初始化下 r2g 比 stage1 更模糊的配置差异（实验1发现）

随机初始化消除 FDK 差异后，r2g 所有视角 `edge_contrast` 系统性低于 stage1（0.60~0.88 vs 0.67~0.90），说明模糊源于两模型其他配置差异。候选：

| 配置 | stage1 | r2g | 对模糊的影响 |
|------|--------|-----|-------------|
| SSIM 权重 | w_ssim_loss=1.0（L1:SSIM=1:1） | lambda_dssim=0.25（L1:SSIM=1:0.25） | stage1 强 SSIM 保留结构 → 更锐 |
| 3D-TV | 无 | lambda_tv=0.05 | r2g TV 平滑密度 → 更模糊 |
| 形变模型 | HashGrid（tcnn，x_multires=13） | 纯 MLP（傅里叶 PE） | HashGrid 高频细节强，MLP 平滑 |
| AST | 有（相位噪声） | 无 | AST 可能帮助形变场学习 |
| 密度控制 | 动态百分位 0.98 | 固定 5e-5 | densify 强度不同 |

### 验证实验（deform-blur 候选）
1. r2g 调高 `lambda_dssim` 0.25→1.0（对齐 stage1 SSIM 权重）。
2. r2g 关闭 `lambda_tv`（0.05→0）。
3. r2g 换 HashGrid 形变场（或 BSpline）。
4. r2g 加 AST。
